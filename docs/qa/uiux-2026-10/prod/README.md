# 本番の確認の道具（UI・UX 全面改修 2026-10）

改善を公開するたびに、本番（https://nagoya-bites.com/）で確かめるために使った道具です。作業用の一時フォルダにあったものを、2026-10-13 にここへ移しました（一時フォルダは消えるため）。使うのは、リポジトリの `node_modules` の `puppeteer`、`curl`、`gh`、Python 3 だけです。

どれも本番を読むだけで、サーバーに何も書きません。GA4 などの分析への通信は止めます。出力に Google マップのキーが混ざる場合に備えて、`run_all.sh` は `[KEY]` に置き換えます。個別に実行して出力をほかへ書き写すときは、`| sed -E 's/A''Iza[0-9A-Za-z_-]+/[KEY]/g'` を付けてください。

## 一式をまわす

```
docs/qa/uiux-2026-10/prod/run_all.sh [--base=https://nagoya-bites.com]
```

変更ごとの確認 7 つ・トップのスモーク・計測イベントを順にまわします（約 1.5 分）。最後に `exit=0` が出ます。2026-10-13 に実行して、すべて通りました。
