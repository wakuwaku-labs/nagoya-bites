## 2. 理念と「減らす失敗」5つ

理念「飲食店選びの失敗を、情報の力で減らす」はどのページにも書かれていない（①A-1）。5つの失敗のうち、サクラだけが「桜ゼロ宣言」「口コミ信頼度」で前面に出ている。ただし方針の但し書きどおり、**外部情報だけで実際の店の品質を保証することは出来ない**。

### 2-1. サクラレビューや信頼性の低い口コミ
- 今あるもの: 口コミ信頼度（入力9項目はすべて第三者が検算できる事実、公開禁止語の検査あり）。Google の星と件数を店舗ページに表示。口コミ本文は保存も転載もしない（`scripts/lib/review_fingerprint.js:9-14`）。
- 方針で求める状態: 確認済みの事実・口コミ・分析・未確認を区別して見せる。
- 外部情報で出来ること: 星に件数と時点を必ず付ける。件数が少ない・開店直後など「振れやすい条件」を書く。
- 出来ないこと: 口コミが本物かどうかの判定。
- 問題: 特集の星532か所に件数・時点が無い。新店に最低段階 D が付く（`stores/amlie.html:240`）。「そのまま参考にできます」（`stores/J004492723.html:254-258`）が断定。
- 対応: 改善 S2-3・S1-2（決定3）・S5-4（決定1）。維持: 公開禁止語と検査。

### 2-2. 宣伝写真と実際の雰囲気の違い
- 今あるもの: 写真の出所と帰属の検査（`scripts/lib/hero_photo_gate.js`）、汎用ストック写真URLは0件。
- 問題: 過去のジャーナルの Google 写真51本中44本が表示不能、個人名クレジット12/44、自前で置いた7枚が Unsplash 由来、特集のヒーロー写真が掲載外の店のもの16本。写真と実物の違いを読者が見分ける表示は無い。
- 外部情報で出来ること: 写真の出所（店の提供・プレスリリース）を写真のそばに出す。完成予想図は明記。
- 出来ないこと: 実際の雰囲気の確認。確かめ方を記事で案内するまで。
- 対応: 維持（帰属の検査）＋改善 S1-1（素材写真）・S1-5（壊れた写真）。**「出所を写真のそばに出す」は③0-3に書かれているが、施策番号が付いていない**（ギャップ①）。

### 2-3. 来店後に初めて分かる追加料金や利用条件
- 今あるもの: ホットペッパーの料金備考（`budget_memo`）を取得時に捨てている（`build.js:599-660`）。お通し・席料・チャージ・サービス料の語がある店舗ページは5,184本中7本、ジャーナルは171本に語なし。良い手本は一人飲み特集の見分け表（`features/nagoya-solo-dining.html:265-272`）。
- 外部情報で出来ること: **5つの中でいちばん実現しやすい。** 店の公式・掲載情報から確かめて書く。見つからなければ「記載が見つからなかった」と書く。
- 出来ないこと: 店が公表していない条件。ホットペッパーの料金備考の充足率は**未測定**（【取得不可】）。
- 対応: 新規 S2-2（先に規約と充足率）・S3-2（来店前に確かめたいこと）・S3-4（掲載データの集計）、改善 S5-2。

### 2-4. 料理の提供スピードの期待違い
- 今あるもの: 店の提供時間のデータは、店舗データにも記事にも無い（①で確かめた範囲）。
- 外部情報で出来ること: 遅くなりやすい条件（席数と厨房の関係・コースか単品か・混む時間）を「店選びガイド」で一般論として解説する。
- 出来ないこと: **個々の店の提供時間。取れるデータ源が無い。** 取れる前提の設計はしない。
- 対応: 新規 S3-3（店選びガイドの枠）・S3-4。個店の評価は計画に入れない（③8章）。

### 2-5. 接客・清潔感・料理など総合的なサービス品質
- 今あるもの: Google の星と件数、口コミ信頼度、店舗ページの紹介文（経営側の言葉が1,337本）。
- 外部情報で出来ること: 評価の数字を件数・時点つきで事実として示す。
- 出来ないこと: 個々の店の品質の保証。口コミ本文は規約上、保存も転載も出来ない。
- 問題: 星の見出し使い（「驚異的」「異例」）と、口コミ12件前後の「満点を維持」を掲載根拠にした例（①3-3 ④）。
- 対応: 改善 S2-3・S5-4・S1-1。

### 5-1. 「人に確認する条件」: 今と方針の差

## 10. 優先度の付け方

- **P0**＝今、読者を誤解させている・事実と違う。小さく、戻せる形で先に直す。
- **P1**＝新しい記事が方針どおりに出るために要る（型・出所・検査・取り下げ）。
- **P2**＝既存資産の底上げ・測定。検索流入のある記事から、足すだけで直す。
- **P3**＝片付け。

| 優先度 | 施策 | 一言 |
|---|---|---|
| P0 | S1-1 | 裏づけの無い掲載歴・訪問済・休業中の店・星のずれ |
| P0 | S1-2（決定3）・S1-3（題は決定4）・S1-4 | 言い過ぎの言い切り、人が選んだと読める言い方、閉業・休業の注記 |
| P0 | S5-4 のうち番号・点数の表示（決定1） | 序列化の見せ方。紹介文の置き換え部分は P2 |
| P1 | S0-1・S2-1・S2-2・S2-3 | 指示文の整合、出典の台帳、料金・条件、星の件数・時点 |
| P1 | S3-1〜S3-4 | 編集基準・判断材料の部品・3分類・集計の型 |
| P1 | S4-1〜S4-5 | 事実台帳と照合・独立した読み手・3つの道・取り下げ・本番切替 |
| P1 | S6-2（決定5） | 編集規約（約束が実態を追い越さない順番） |
| P2 | S1-5・S5-1・S5-2・S5-3・S5-5 | 壊れた写真、棚卸し、確認メモ、重複・季節切れ、公開後の鮮度 |
| P2 | S6-1（決定2）・S7-1〜S7-3 | 看板の組み替え、信頼の指標・読者の声・KPI |
| P3 | 削減 | 使っていない物・台帳の三重管理・役割文書の整理 |

- 決定待ち（決定1〜4）の施策も、決定が出ていない部分から先に進められる（③3章）。

## 付. 分析で見つけて③に反映した点

この分析の途中で「③に対応する施策が無い」と分かった4点。どれも③に反映済み。

1. **写真の出所を写真のそばに出す**（失敗②）→ ③S3-2 の部品に入れた（出所の表示に、店の提供写真・プレスリリース・完成予想図の種類を添える）。

4. **GA4の汚染（11-11以降）と内部リンク**（①5-0・D-5）→ GA4 は「範囲外の気づき」に記録。内部リンクは本数を①D-5 に集計し、③S5-1（台帳に、ほかのページからリンクされている数の列）と③S5-4（記事で扱っていない店の店舗ページから、エリア・用途の店選びガイドへのリンク）に入れた。記事で扱った店から記事へ戻るリンクは既に出来ており、変更不要。
