## 3分で読む要約

**今の姿**
- 日次ジャーナルは既に全自動で毎日公開されている（直近31日で31本・見送り0）。ただし公開の条件は「形式の検査に通ること」で、本文の事実と出典を照らす検査や、書き手と別の目で読む段は無い。
- 編集原則10のうち、はっきり反しているのは「星・点数で序列化しない」だけ（星の高い順に番号を振る一覧805本、番号つきの特集63本、口コミ信頼度 SS〜D と点数）。「広告費・掲載料で順位を変えない」は表明と実装が一致していて、変更不要。
- いま読者を誤解させうる表示が残っている: 裏づけの無い「掲載歴」12か所、記録の無い「編集部訪問済」、「やらせ口コミは1件もありません」の言い切り、人が選んだと読める言い方395ページ。
- 新方針にいちばん近い資産は日次ジャーナル（出典・推測の言い分け・注意点がある）。検索の成果は伸びている（Google のクリックは4か月で約6倍）。

**計画の中身**
1. 記事を「判断材料」の形にそろえる（確認できたこと／分からないこと／来店前に確かめたいこと／向く人・向かない人／出所と確認日）。
2. 書いた内容を、書き手と別の仕組みが出典と照らして確かめてから公開する。確かめられない文は「未確認」に落とすか、その日は出さない。まず記録だけで動かし、数日で確かめ、本人の承認後に本番の条件にする。
3. 読者を誤解させうる表示を先に直す。検索流入のある記事は、題・URL・冒頭を変えずに足すだけにする。

**規模**: AI の作業 約130時間（暦で3〜4週）。本人の時間は合計1時間半ほど。新しく毎月かかる費用は0円の見込み。新しい AI の役割は足さない。

**正直に書いておくこと**: 「提供スピード」「接客・清潔感」は、外部から取れるデータ源が無い。個々の店については「確認できない」と書き、選び方の解説で補う。出来ないことを出来るように見せる施策は入れていない。
