# 0027 外部の画像変換サービス（wsrv.nl）を使い続ける

- 日付: 2026-10-13
- 状態: 採用
- 関連: Linear P-237 #5（決定）・P-325（この記録）・P-235（親）/ `data/image_source_policy.json` / `scripts/audit_image_sources.js` / `scripts/nightly_qa.js`（`image-sources`）/ 設計書 I-09（設計用ブランチ `wakuwaku-labs/mooneye` の `docs/uiux-overhaul-plan-2026-10.md`）

## 背景
- 店の写真を、画像変換サービス wsrv.nl（旧ドメインは images.weserv.nl）経由で配っている。使い道は 3 つ。
  - 店舗ページのヒーロー写真（HotPepper の公式写真）。WebP 化・縮小・シャープ化し、幅ごとの srcset を作る（`gen-store-pages.js`・ISSUE-073）。
  - 店舗ページの `og:image` と `twitter:image`。自作の SVG（`assets/og/`）を PNG にして SNS のカードに出す（`gen-store-pages.js`・ISSUE-036）。
  - トップのカード・モーダル・ランキングの写真（`index.html` の `nbImage()`・ISSUE-049）。
- 2026-10-13 の数え方（`node scripts/audit_image_sources.js`）では、公開ページ 6,134 本のうち 4,850 本・23,914 か所（店舗ページ 4,849 本とトップ 1 本）。
- 懸念は 3 つ（`data/image_source_policy.json` の `why`）。
  1. リクルートの利用規約が、写真の加工・複製保存・再配信を禁じている疑い（読み方は確かめていない）。
  2. 外部のサービスが止まると、店の写真が全部出なくなる。
  3. 初めて見られる店の店舗ページの LCP が遅くなる。設計書 U-84 の実測では、同じ店を測り続けると wsrv.nl 側にキャッシュができて 1.8s、店を替えると約 7s。写真を直接取ると、初めて見られる店は 2.9〜4.4s・2 回目以降は 0.07〜0.4s だった（`CLAUDE.md` の `perf.js` の行）。
- 設計書の I-09 は、写真を直接配信に切り替えてこの 3 つを減らす案。オーナーに「やめる（おすすめ）／リクルートに問い合わせてから決める／続ける」で聞いた。
- オーナーの決定（2026-10-13・P-237 #5）:「画像変換サービス: **続ける**」。おすすめ（やめる）とは違う答えで、理由は添えられていない。

## 決めたこと
1. wsrv.nl 経由の配信を**続ける**。I-09（直接配信への切り替え）は実装しない。`nbImage()` と店舗ページのテンプレートは変えない。
2. 検査（`scripts/audit_image_sources.js`・夜間QA の `image-sources`）は残し、**soft のまま件数を見張る**。0 件にするのが目標ではないので**赤のままが平常**で、hard には上げない（毎晩 Issue が立つだけになるため）。件数は夜間QA の報告に毎晩出る。
3. 方針 JSON の `blockedHosts` は、名前を変えずに「直す対象」ではなく「見張る一覧」と読む（検査の動きを変えないため）。決定は同じファイルの `ownerAnswer` に残した。
4. リクルートの利用規約の読み方は、**確かめないまま続ける**。確かめるか（リクルートに問い合わせるか）は、オーナーが決める。
5. 店舗ページの LCP の基線は、これまでどおり店を替えて測る（`perf.js` の `store-sample`）。同じ店を測り続けると、wsrv.nl のキャッシュで速く見える。

## 選ばなかった案と理由
- **やめる（直接配信に切り替える）**: おすすめだった案。オーナーは選ばなかった。理由は示されていないので、ここに推測で書かない。
- **リクルートに問い合わせてから決める**: 同上。問い合わせは見直す条件の 1 つとして残す。
- **検査を消す**: 規約の読み方を確かめていないリスクの大きさが、誰にも見えなくなる。
- **検査を hard に上げる**: 決まったうえで続けているものに、毎晩 Issue が立つ。

## 見直す条件
- リクルートから回答があったとき。
- wsrv.nl が止まった・規約が変わった・料金や回数の制限が付いたとき。
- 初めて見られる店の店舗ページの LCP が、設計書の目標に届かない状態が続くとき（`store-sample` の基線で見る）。
- どれかが起きたら、この記録を置き換える判断として先に書く。
