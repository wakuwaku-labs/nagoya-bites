# 0012 食べログリンクは名前が一致しても住所が別の場所なら採らない（住所は3値で比べる）

- 日付: 2026-10-09
- 状態: 採用
- 関連: Linear P-163（ISSUE-159）・P-162（ISSUE-158・親）・P-164（ISSUE-160）・P-161（ISSUE-157）/ `scripts/lib/store_link_identity.js`・`scripts/audit_store_link_identity.js`・`scripts/audit_tabelog_branch_mismatch.js`・`scripts/resolve_manual_tabelog_links.js`・`tests/store_link_identity.test.js`

## 背景
- 「うなぎのしろむら 丸の内店」（中区丸の内2-8-27）の食べログリンクは、東区泉1-18-41 の泉本店のページを指していた。照合器は「一致」と記録していた（ISSUE-157）。
- 食べログの題名は「うなぎのしろむら - 高岳/うなぎ | 食べログ」のように支店名を持たないことがある。照合器（`namesMatch`）は「うなぎのしろむら 丸の内店」と「うなぎのしろむら」を一致（sim 1）と判定するので、同じ屋号のどの支店にも一致してしまう。
- 照合キャッシュで名前だけが一致したリンクは 469 件。そのうちページの住所を持つ 315 件を掲載住所と比べた（ISSUE-158 の起票時の数字）。
- 住所の文字列の完全一致（`normalizeJpAddress`）では、表記ゆれ（字・漢数字の丁目・ヶ/が・全角空白の区切り）でも「違う」になる。これを不一致の根拠にすると、正しいリンクまで落とす。

## 決めたこと
- **名前が一致しても、住所が別の場所なら不一致にする**（reason `branch-address-mismatch`）。名前が一致しない場合と同じく、監査の不一致一覧に載る。
- **住所の比較は3値**（`compareJpAddress`）: same / different / unknown。
  - 比べる要素: 都道府県、市町村、名古屋市の区、町名、番地の頭の数字（丁目か番地）。
  - 町名は、字・大字・漢数字の丁目・ヶ/ケ/が・の/ノを畳む。全角空白は番地の区切りとして扱う。
  - different にするのは、表記ゆれでは説明できない違いだけ: 市町村が違う、区が違う、町名が同じで丁目が違う、町名が違って番地の並びも違う。
  - 町名が似ていて番地が同じ組（「金山町」と「金山」、「四軒屋」と「四軒家」）は unknown。番地がまるごと同じで町名が違う組も unknown。unknown は落とさない。
  - 片方の住所が無い、または番地を読めないときも unknown（何も主張しない）。
- **我々の住所は HotPepper の掲載住所を優先する**（`data/stores.json` の「住所」）。Google Places の住所は、HotPepper の住所を持たない店（手動キュレーション店）だけに使う。Places の紐付け自体が別の支店を指す店があるため（ISSUE-147・丸の内店は泉本店に紐付いている）。
- **リンクを外すのは人が確かめてから。** different と判定されたリンクを自動では外さない。ISSUE-160 で1件ずつ、リンク先の住所と掲載住所を見てから外す。`clear_broken_tabelog_links.js` の対象にも入れない。
- **キャッシュの「一致」も数え直す。** 照合キャッシュは60日持ち越すため、`scripts/audit_tabelog_branch_mismatch.js` がキャッシュの事実だけで比べ直す（外部へは問い合わせない）。夜間QA が soft で数え、0件になってから hard に上げる。
- **手動キュレーション店の解決器も同じ向きの取り違えを採らない。** `resolve_manual_tabelog_links.js` は、「我々は支店名を持つ・相手は支店名が無い・区が違う」候補を採らない（`branch-locality-mismatch`。実例: 柳橋本店に泉本店のページ）。支店名の判定は判定器の `hasBranchSuffix` の1本で、読み仮名の丸括弧は外して見る。

## 選ばなかった案と理由
- 正規化した住所の完全一致を条件にする案: 表記ゆれで正しいリンクを落とす。2026-10-09 に比べた 2,116 件のうち、町名と丁目は同じなのに文字列が違う組が 97 件あった（号の省略・階数・表記の違い）。
- 番地の下位（号）まで一致を求める案: 食べログ・HotPepper のどちらかが号を省く店がある。違う店の取り違えは町名か丁目で分かれるので、頭の数字で足りる。
- different をその場で自動で外す案: 移転前と移転後の住所の組（嘉文 徳重店・サガミ 有松店など）は、同じ店でも different になる。外すのは人の確認の後にする。
- 店名に支店名が無い食べログのページを一律に落とす案: 1店舗だけの店は題名に支店名を持たない。住所が同じなら正しいリンク。

## 見直す条件
- 愛知県外の店を扱うとき（市町村の一覧は愛知県だけ）。
- 京都の通り名のように、町名より前に別の表記が入る住所が増えたとき。
- unknown が増え、人の確認が追いつかないとき。表記ゆれの規則を足す前に、実例で分布を見る。
