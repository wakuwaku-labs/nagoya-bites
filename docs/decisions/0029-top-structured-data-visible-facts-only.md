# 0029 トップの構造化データに、画面に無い主張と運営者の個人情報を載せない（FAQPage と founder を外す）

- 日付: 2026-10-13
- 状態: 採用
- 関連: Linear P-328（親 P-235・UI・UX全面改修）/ 計画 I-04・4.4 節 #2 / 判断の記録 0025（特集の FAQPage。範囲外にしたトップをここで扱う）/ `index.html`（JSON-LD）/ `llms.txt` / `manifest.json` / `tests/selection_wording_sources.test.js`

## 背景
- トップ（`index.html`）の構造化データは、Organization・WebSite・WebPage・FAQPage の 4 本だった。
- FAQPage は 21 問あった。どの問いも、トップの画面には出ておらず、構造化データにだけ書かれていた。答えには、事実と違う、または第三者が確かめられない主張が混ざっていた（例:「現役飲食人の判断のみで店舗を選定」「Google評価4.3以上かつ編集部が目利きした店のみを優先表示」「2026年5月時点で4,584店」、店ごとの待ち時間）。
- Organization の `founder` は、氏名・肩書（編集長）・経歴・得意分野を持っていた。
- オーナーの指示（2026-10-11）:「店舗の選定にはAIによる情報収集・分析を活用しています。人間の飲食業界関係者がすべての店舗を選定しているような表現は使用しないでください。」
- オーナーの決定（2026-10-13・計画 4.4 節 #2「店の選び方の説明」）: 書き換える。運営者の経歴は載せない。個人名は外す。
- 判断の記録 0025 は、トップの FAQPage を範囲外として残した（オーナーの決定が「特集」と「ハブと同じ」だったため）。トップは計画 I-04（「画面に出している問いと事実だけにする」）で扱う。
- FAQ のリッチリザルトは 2026-05-07 から表示されない（`scripts/gen_area_genre_pages.js` の注記・SEO-124）。FAQPage を出さなくても、検索結果の見た目は変わらない。

## 決めたこと
1. **トップの JSON-LD から FAQPage を外す。** トップには画面の「よくある質問」が無く、「画面に出している問い」は 0 件のため。よくある質問は `faq.html`（画面の質問と構造化データが同じ場所にある）に置く。
2. **Organization から `founder`（氏名・肩書・経歴・得意分野）を外す。** 運営者の氏名・所属は非開示（`features/editorial-policy.html`）。
3. **Organization・WebSite・WebPage の説明文を実態に合わせる。** 選び方は、オーナーの文「店舗の選定にはAIによる情報収集・分析を活用しています。」を使う。WebPage の `name` からは「業界人が厳選」を外し、掲載数の事実だけにする（`<title>` と本文の言い方は P-330、`<title>` の変更の順は計画 8.4 節）。
4. **同じ事実を、`llms.txt` の手で書く部分と `manifest.json` の説明にもそろえる。** `llms.txt` の特集一覧（自動生成）は各特集の説明文から作られるので、特集を直す P-331 で変わる。`llms.txt` の「データ層」から、画面に出していない `insiderNote` の説明を外した（SEO-143 と同じ理由）。
5. **検査で止める。** `tests/selection_wording_sources.test.js` が `npm test`（blocking）で、(a) トップの JSON-LD の型が Organization・WebSite・WebPage だけであること、(b) FAQPage・`founder`・`Person`・`jobTitle` が無いこと、(c) 人が選んだと読める言い方が無いこと、を見る。`llms.txt` の手で書く部分と `manifest.json` にも (c) をかける。

## 選ばなかった案と理由
- **事実だけに直した FAQPage を残す**: 画面に同じ問いが無いので、「構造化データは画面に見える内容と一致する」を満たせない。画面に FAQ を足すかはトップの作り直し（段階 3）の判断で、構造化データのために画面を増やさない。
- **`founder` を残して肩書だけ直す**: 氏名・所属は非開示という編集規約と食い違う。
- **FAQPage を戻すために画面へ FAQ を足す**: 検索結果の見た目が変わらないので、画面のスペースと手間に見合わない。

## 見直す条件
- トップに画面の「よくある質問」を置いたとき。戻すときは、画面の問いと一字一句そろう形で、データから生成して出す。手で書かない（0025 と同じ）。
- オーナーが運営者の氏名・経歴を公開すると決めたとき。そのときは、編集規約と「運営について」を先に直し、構造化データを後からそろえる。
