# 0016 店の選び方は実態どおりに書き、人が全店を選んだと読める言い方をしない

- 日付: 2026-10-11
- 状態: 採用
- 関連: backlog DSN-013・DSN-015 / `docs/uiux-overhaul-plan-2026-10.md`（3.1 節・5.5 節・8.4 節）/ `scripts/lib/site_chrome.js`・`scripts/score_journal_candidates.js`・`scripts/lib/editor_reason.js`

## 背景

- オーナーの指示（2026-10-11）: 「店舗の選定にはAIによる情報収集・分析を活用しています。人間の飲食業界関係者がすべての店舗を選定しているような表現は使用しないでください。」
- 2026-10-11 に数えると、公開中の HTML 6,129本のうち 6,013本（98.1%）に、人が全店を選んだと読める言い方があった。例: トップの見出し「飲食のプロが、名古屋だけを深く選んだ。」、フッター「現役の飲食店マネージャーが編集する」、特集「業界人が厳選」、ジャーナルの題「〜を業界人が読む」。数え方は `node docs/qa/uiux-2026-10/counts.js`。
- 言い方の出どころは、サイト共通のフッター（`scripts/lib/site_chrome.js`）ほか約10か所。日次ジャーナルの採点は「業界人」「現役」「目利き」などの語に加点している（`scripts/score_journal_candidates.js:136`）。

## 決めたこと

1. サイトの文（画面・title・説明文・構造化データ・OG・SNS 原稿）で、「業界人」「現役の店長」「飲食のプロ」「中の人」を、店を選んだ人・文を書いた人の意味で使わない。
2. 店の選び方は実態どおりに書く。AI で情報を集めて分析していることを隠さない。
3. 人が確かめたことは、確かめた記録があるときだけそう書く。選定理由の根拠は、今の `scripts/lib/editor_reason.js` の語（訪問済・店主取材済・公開情報ベースなど）を使い続ける。
4. 選び方の説明は `editorial-policy.html` の1か所に置き、各ページからはそこへリンクする。
5. 守る時期:
   - Claude が手で書く文（設計書・課題・新しい文書）は、この日から守る。
   - 自動で作る文（日次ジャーナルの題・特集の生成・共通フッター）と既存ページは、生成の手順と採点を直すときに変える。サイトのコードを変えるので、DSN-013 の承認後に行う。
   - title の書き換えは検索順位に響きうるので、設計書 8.4 節の順（説明文・本文・フッターが先、title は GSC の表示が多い順に分けて、前後を比べる）で進める。
6. 運営者の経歴をどこまで書くか、CLAUDE.md の競争優位の書き方、`.claude/commands/journal-today.md` の言い方は、オーナーが決める（DSN-015・設計書 4.4 節の2・10・11）。決まるまでは 1〜4 の側に倒す。

## 選ばなかった案と理由

- 今の言い方を残し、「AI を活用しています」と注記を足す案: 見出しや題の主張と注記が食い違い、読者を誤らせる。指示は「表現を使用しない」こと。
- 既存ページの title を一度に全部書き換える案: 書き換えた本数が多いほど、検索の数字が動いたときに原因を切り分けられない。

## 見直す条件

- 店の選び方の実態が変わったとき（例: すべての店を人が確かめる体制になった）。
- オーナーが指示を変えたとき。
