# 0062 X の投稿には文字だけの画像カードをやめ、記事の店の実物写真（プレスリリース）を付ける

- 日付: 2026-11-13
- 状態: 採用
- 関連: data/x_post_policy.json（imageCard・storePhoto）/ scripts/lib/x_store_photo.js / scripts/post_journal_to_x.js / ADR 0027（X 自動投稿・5「写真は X に上げない」）/ 0056（note の見出し画像の線引き）

## 背景
2026-11-12 から、奇数日の X の投稿に自前の画像カード（記事の題・要点・地名とロゴだけの文字の図）を付けていた（imageCard）。
2026-11-12〜13 に本人から指摘があった。「画像の文字が被っている」「この画像は文字ばかりで全然見やすくないし、興味を引かれない」「投稿の数字も全然上がっていないので、ほかのものに替えてほしい」。
重なりは配置の計算の誤りで、先に直した（題が4行の日に要点がフッターに重なっていた）。そのうえで、文字だけの図そのものをやめる。

使える写真の出どころは ADR 0056 で規約を確かめてある。
- PR TIMES のプレスリリースの写真: 企業規約 第6条3項で報道目的の利用を許諾。→ 使える。
- ホットペッパー・Google の写真: 再配信・複製保存を禁止。→ X に上げない。記事の og:image としてリンクカードで見せる（X が記事から読む・2026-11-11 の投稿で店の写真のカードが出ることを確かめた）。

直近40本の記事では、プレスリリースの写真がある日が11日、ホットペッパー等の写真がリンクカードに出る日が20日、写真の無い日が9日だった。

## 決めたこと
1. 文字だけの画像カードを止める（imageCard.enabled=false）。仕組みは残し、戻すのは設定の1行。
2. 記事にプレスリリースの写真があれば、それを加工せずに（配信元の縮小版・幅1920）X に上げて付ける。選び方は note と同じ（ヒーロー → 本文の順・クレジットのあるものだけ）。
3. 本文の最後に「写真: 提供 ◯◯（プレスリリースより）」を1行足す。280 を超えるなら短い形「写真: ◯◯提供」、それでも超えるなら写真を付けない。
4. 写真はリポジトリに置かない（投稿のときに取ってきて、上げたら捨てる）。
5. 取れない・上げられない・写真つきが断られたときは、写真とクレジットの行を外して送る。台帳の media は photo／none、理由は media_reason。
6. 写真が無い日は何も付けない。URL を載せる日はリンクカードで店の写真が出る。

## 選ばなかった案と理由
- 文字のカードの見た目を良くする: 本人の指摘は「文字ばかりで興味を引かない」こと。写真が主役の方が目を引く（note の見出し画像の方針 L51 と同じ）。
- ホットペッパーの写真を上げる: 規約が再配信を禁止。
- 生成画像: 店の実物ではない（ADR 0056 と同じ）。
- 写真の上に題を重ねる: 加工にあたる（ADR 0056 と同じ）。

## 見直す条件
- 写真つきの投稿と無い投稿の表示回数を2週間比べ、差が無ければ別の案を考える。
- 店から写真の利用許諾を得られたとき（storePhoto.sources に足す）。
