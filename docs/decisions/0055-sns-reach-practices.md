# 0055 note と X の出し方を、運営の公式情報と政府統計に合わせる

- 日付: 2026-10-24
- 状態: 採用
- 関連: docs/sns-reach-research-2026-10.md / data/x_post_policy.json（postSlot・maxHashtags）/ data/note_post_policy.json（tags）/ scripts/x_post_wait.js / scripts/lib/note_draft.js / ADR 0047（X の文面）・0054（note の抜粋）

## 背景
オーナーから「媒体ごとに多く見られる出し方に沿って投稿してほしい」と依頼があった（2026-10-24）。始める前の数字は X が表示 3〜19 回・フォロワー 0、note がフォロワー 0（調査メモの表）。
また X は 10-21・10-22 に、記事の公開と文面が別の push で届いたため、保存した文面ではなく定型の文面で出ていた。

## 決めたこと
1. **X は平日 12:00（JST）に出す。土日は公開の直後に出す。** 総務省の時間帯別ネット利用で、平日は 12 時台（34.2%）が朝 9 時台（22.5%）の約 1.5 倍。休日は 9〜12 時台の差が小さい。`scripts/x_post_wait.js` が枠まで眠り、眠った後に main を取り込み直し、文面がまだ無ければ最大 15 分待つ（定型に落ちた原因の対策を兼ねる）。眠る長さは 300 分まで（ジョブの上限 330 分に収める）。手動実行の `post_now` で待たずに出せる。
2. **X のハッシュタグは 1 個（#名古屋グルメ）にする。** 地名は本文の題名に入るので検索に掛かる。タグを増やす根拠は無い。
3. **X のリンクは本文に残す。画像は付けない。** リンクの減点は撤廃済みで、返信に移しても費用は同じ（0.20 ドル）。公開アルゴリズムはリンクを開くことを加点に数える。画像を付けると写真つきのリンクカードが消え、HotPepper の写真は規約上アップロードできない。
4. **note のハッシュタグは 5 個前後にする。** note 公式ヘルプの「5 個ぐらい」「種類・テーマ・シリーズ・関連語」に合わせ、基本（名古屋グルメ・名古屋）→ 地名 1 つ（題名に出る順、無ければ店のエリア）→ テーマ最大 2 つ（題名の語・店のジャンル）→ 埋め草（グルメ）で 5 個まで。**記事の題名か店のデータにある語だけを使う**（関係の無いタグはスパム判断の恐れ・読者を裏切る）。語の表は `data/note_post_policy.json` の `tags`。
5. **note の見出し画像は付ける**（#676 で実装済み。公式ヘルプで PV・スキが数十%多い）。
6. **note の投稿時刻は変えない。** 予約投稿は有料会員だけで、時刻の効果は小さい。1 年後の流入の 64% は検索なので、時刻より題名とタグの方が効く。

## 選ばなかった案と理由
- X を夜 21 時台に出す: ネット利用は最も多いが、GitHub の 1 ジョブは最長 6 時間で、定時実行は約 5 時間遅れる（実測）ため確実に狙えない。Mac 側で投稿すると鍵を Mac に置くことになり、0047 の構成を崩す。
- X のリンクを返信に移す: 減点の根拠が無く、費用も同じ。本文のリンクカードが消える。
- X に画像を付ける: リンクカードが消える。使える写真の出典が無い（CLAUDE.md 写真ソース）。
- note でハッシュタグを 10 個（上限）まで付ける: 公式の目安は 5 個前後。関係の薄い語はスパム判断の恐れ。
- note のみんなのフォトギャラリーを見出し画像に使う: 汎用のストック写真に当たり、写真の決まり（制約 9）に反する。
- note を全文掲載に切り替える: 0054 のとおり二重掲載を避ける。抜粋の方針は変えない。

## 見直す条件
- 2026-11-07 ごろに X の表示・いいねと note のスキ、GA4 の `utm_source=x` / `utm_source=note` を始める前の数字と比べ、変化が無ければ時刻・タグの方針を見直す。
- X か note が公式に推奨を変えたとき。総務省の新しい年度の調査で時間帯の順位が変わったとき。
