# 0071 段階1: 読者を誤解させうる表示を直した方法と、上位2本の題の扱い

- 日付: 2026-11-17
- 状態: 採用
- 関連: 0069（本人の決定1〜8）／0033（題の系統の持ち越し→この記録で置き換え）／0029／0045／docs/plans/media-policy-2026-11/03-implementation-plan.md S1-1〜S1-5／Ondine #2048

## 背景
- 基本方針の反映の段階1。「掲載歴」「編集部訪問済」「食べログ4.x」「桜ゼロ宣言」「業界人が厳選」「閉業の店」「壊れた Google 写真」など、読者に誤解を与えうる表示を直す。

## 決めたこと
1. **訪問済・店主取材済**は、訪問・取材の日付の記録（`visitedOn`）がある店だけに出す。無い店は「公開情報ベース」と出す（0069 決定8・今は記録を出せる店が無いので全店で外れる）。`scripts/lib/editor_reason.js`・`index.html` のモーダル・`gen_industry_features.js`。
2. **星**: 特集の本文の★は `data/stores.json` の Google評価と一致するものだけ。違う★は今のデータに直し、データに無い★は外す（`scripts/audit_feature_facts.js` が毎日検査）。「食べログ4.x」は出所の取り違えだったので、数字を出さず「高い口コミ評価」と言う（元データの editor_picks・manual_stores・stores も同じ）。出典つきの引用（「食べログ4.5超え」）は残す。
3. **言い切り**（0069 決定3 = A）: 「桜ゼロ宣言」「サクラなし」「やらせ口コミは1件もありません」「そのまま／文句なしに参考にできます」を、編集部の行いの約束（口コミを書かない・書かせない・掲載料・広告費を受け取らない）と、「確認できた範囲では、偏りは小さい」に言い換えた。ページの呼び名は「編集の約束」。検査は `data/trust_display_policy.json` の `assertionWords`。
4. **「業界人」などの語**（0069 決定4 = A）: 題・本文・構造化データから外した（規則は `scripts/lib/selection_wording_rules.js`、実行は `scripts/rewrite_selection_wording.js`・冪等）。検索流入の上位2本（一人飲み・手羽先）の題だけは別に扱い、**2026-11-17 に変えた**。記録と戻す条件は `data/top_title_changes.json`（28日のクリックが変える前の半分以下なら `--revert <id>`・比較は 2026-12-16 以降）。
5. **閉業・一時休業**は店を外さず、「Google では「閉業」と表示（◯月◯日確認）」の事実の注記を店舗ページと特集の店カードに出す（`scripts/lib/operating_notice.js`・`scripts/sync_feature_closure_notes.js`・日次）。人の確認で営業中とした店には出さない。新しい記事・特集の掲載店には選ばない。記事の検査（項目3）は、今は**記録だけ（WARNING）**で、公開を止める条件にするのは決定6の検証と本人の再承認の後。
6. **Google の写真**: 記事（ジャーナル・特集）の期限切れ・個人名クレジットの写真を外した（同じ店の生きたホットペッパー写真があれば差し替え）。月次の確認は `.github/workflows/article-photo-watchdog.yml`。Unsplash 由来だった特集7本の顔写真は、記事専用の図（`scripts/gen_feature_theme_figures.js`）に替えた。古い jpg 14枚は参照を外しただけで、削除は本人に一覧を見せてから。

## 選ばなかった案と理由
- 題の一括変更に上位2本も含める → 10月の題の書き直しが悪化して戻した前例があり、決定4が「最後に1本ずつ・半減で戻す」と決めたため、記録つきで別に変えた。
- 閉業の店の自動除外 → 虚偽の通報で店を消さないため、一次情報での確認（`data/closed_stores.json`）の決まりは変えない。

## 見直す条件
- 上位2本のクリックが半減したら戻す。閉業の注記の誤り（営業中の店に出た）が見つかったら、その店を `data/store_liveness_reviews.json` に「営業中」で記録する。
