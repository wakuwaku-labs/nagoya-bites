## 背景
2026-11-13 のブランドの2択（AI組織設計 #1906 の03）で、本人は B（写真の日の note 見出し画像は、写真の下部に題と日付を重ねる・10/23 #676 の型）を選んだ。
その後 #1914 で PR TIMES の規約を確かめ、改変してよいとも、してはいけないとも書かれていない（灰色）と分かったため、ADR 0064 で「写真に重ねず、写真の下に別の帯を足す」形にした。
同じ日（2026-11-13）、本人は灰色であることの説明を受けたうえで「写真に重ねて」と指示した。この ADR はその指示を記録し、0064 と 0056 の「重ねない」を置き換える。

## 決めたこと
1. 写真の日の見出し画像は、写真を全面（1280x670・note の比率）に敷き、上と下に暗い影（上 35%→0・中ほど 22〜45% は影なし・下 0→72% の黒）を重ね、左上に「NAGOYA BITES JOURNAL」、下部に題（明朝・白・最大2行）と「日付 ／ 名古屋の飲食店ジャーナル」（白）を載せる。見本 03-b.png と同じ型。
2. 写真の色は変えない（フィルタ・色調補正なし）。比率合わせの中央の切り抜き（object-fit: cover）だけを許す。
3. **重ねてよいのは PR TIMES の報道目的のリリース写真だけ**（`overlayAllowed`: prcdn.freetls.fastly.net・prtimes.jp）。ホットペッパー・Google の写真は、規約が加工・複製保存を禁じているので、今までどおり見出し画像に使わない（data/note_post_policy.json の eyecatchPhoto.sources は press のまま）。もし PR TIMES 以外の写真が来ても、題は重ねず写真だけを上げる。
4. 安全側（写真だけにする日）: 比率合わせで残る写真の割合が50%を切る（4:5・縦長・4:1 より細い横長）か、切り抜いた写真の幅が640px 未満（2倍超に引き伸ばしてぼやける）日は、重ねず写真だけにする（0064 の 3a に相当）。
5. 題は語の途中で折らない（Intl.Segmenter の語単位・`findWordBreaks` で検査）。48→44→40px の順で試し、2行に収まらない・はみ出す・ラベルや日付に重なるなら、例外にして写真そのままに落とす（post_note.js）。
6. クレジット（発行元とリリースの URL）は、今までどおり note の本文に書く（ADR 0056 の 3）。
7. 写真が無い日の見出し画像（明るい地の題と日付の図）と、X の画像カードは変えない。

## 規約上の位置づけ（本人が承知のうえで選んだ）
PR TIMES 企業規約 第6条3項は報道目的の無償利用を許諾しているが、加工の可否は書いていない（Ondine #1914）。題を重ねるのは灰色。本人は 2026-11-13 にこの説明を受けたうえで、重ねる形を指示した。
CLAUDE.md の写真ソースの優先3 条件 d（加工しない・self-host しない）は自サイトの表示の決まりで、note の見出し画像はこの ADR を正とする。
