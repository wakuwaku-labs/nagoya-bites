# 判断の記録（ADR）

後から効く判断を、Claude が指示を待たずにここへ残す。番号は4桁の連番、ファイル名は `NNNN-<英小文字の題>.md`。

## いつ書くか
- 複数の案から1つを選び、その選択が今後の作業や運用を縛るとき（閾値・既定値・構成・運用ルール・やらないと決めたこと）
- 一度決めたことを覆すとき（古い記録の `状態` を `置き換え済み（NNNN）` にし、新しい記録を作る）

書かないもの: 1回限りの実装の細部、コードやコミット履歴を読めば分かること。

## 書式

```markdown
# NNNN 題（何を決めたか）

- 日付: YYYY-MM-DD
- 状態: 採用 | 置き換え済み（NNNN）
- 関連: Linear P-NN / backlog ID / ファイル

## 背景
## 決めたこと
## 選ばなかった案と理由
## 見直す条件
```
