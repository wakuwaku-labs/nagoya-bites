# 0052 古い店舗ページ（stores/M0000xx.html）32本の扱いと、開けない口コミ導線の除去

- 日付: 2026-10-19
- 状態: 採用
- 関連: Linear P-445（親は P-246・PR #591 の調査）/ `scripts/lib/store_orphans.js` / `gen-store-pages.js` の孤児処理 / `data/manual_stores.json` / `tests/store_old_m_pages.test.js`

## 背景
- `stores/M0000xx.html` の32本は、今の `gen-store-pages.js` が作るページではない（sitemap に無い）。うち11本は誘導ページ。
- 口コミ導線（`#store=M…&review=1`）を持つのは `M000006`（麺や 六三六）と `M000058`（割烹 季節料理 花わさび）の2本だけ。`index.html` は `review=` を読まないので押しても開かない。どちらも今の `data/stores.json` に無い。
- 2店は `data/manual_stores.json` にあり、写真の実在検証が `name-mismatch` で3回失敗している。閉店の一次情報は無い（`data/closed_stores.json`・`store_liveness_reviews.json` に記録なし）。

## 決めたこと
1. **M000006・M000058 は閉店と決めず、「現在掲載していません」の noindex 案内に置き換える**（口コミ導線・canonical を持たない）。閉店の根拠（独立した2つ以上の情報源）が無いので `closed_stores.json` へは入れない。実在検証を通れば通常の掲載として別スラグで復帰する。
2. 案内ページには印 `nb-orphan-notice` を付ける。誘導ページの印（`nb-orphan-redirect`）とは別なので、誘導ページの判定・内部リンク監査には影響しない。manual_stores に同名があるため、孤児の処理でも「保留」のままで消えない。
3. 残り30本の扱い（理由つき）:
   - 誘導ページ11本（M000001・007・013・014・015・018・019・023・024・036・075）: 現役の店ページへの誘導先が生きているので残す。
   - 手動店の古いページ19本（M000059〜074・076〜078）: 口コミ導線は無い。manual_stores に同名があり、実在検証待ちで一時的に外れている可能性があるため、孤児の処理どおり「保留」で残す。sitemap に無く被リンクも無い。検証を通った店は新しいスラグで通常ページになり、通らないまま閉じる店は閉店の確認後に消す。
4. 再発防止: `tests/store_old_m_pages.test.js` が、M ページに `review=1` が戻らないことを見張る。

## 選ばなかった案と理由
- 2ページを消す: 手動店の同名があり、孤児の処理の方針（現役候補を消さない）に反する。
- 閉店として closed_stores に入れる: 一次情報で確かめていない（制約10・架空店ブロック）。

## 見直す条件
- 2店の実在が確認できた（通常ページで復帰）／閉店が確認できたとき。保留の19本も同じ基準で扱いを決める。
