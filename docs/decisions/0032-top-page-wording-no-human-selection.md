# 0032 トップページの題・説明・店のモーダルとカードの言い方を、人が選んだと読めない言い方にする

- 日付: 2026-10-13
- 状態: 採用
- 関連: Linear P-330（親 P-235・UI・UX全面改修）/ 計画 I-03c・4.4 節 #2・5.5 節 / 判断の記録 0029・0031 / `index.html` / `data/selection_wording_policy.json` / `tests/selection_wording_sources.test.js`

## 背景
- オーナーの指示（2026-10-11）:「店舗の選定にはAIによる情報収集・分析を活用しています。人間の飲食業界関係者がすべての店舗を選定しているような表現は使用しないでください。」
- オーナーの決定（2026-10-13・4.4 節 #2）: 書き換える。運営者の経歴は載せない。個人名は外す。運営について・FAQ・編集規約・店舗一覧は 0031 で直した。
- トップ（`index.html`）の手書きの部分には、次の言い方が残っていた。
  - 題・説明・OGP・Twitter・構造化データの説明: 「現役の飲食店マネージャーが選ぶ」「選び直しました」「現役の飲食店マネージャーによる」「現役飲食店マネージャーが厳選した」。
  - 実績の帯: 「現役の店長が編集」。
  - 店のモーダル: 署名「現役飲食店マネージャーが編集」、区画名「編集部の視点」「業界人メモ」「業界人レビュー」。
  - 店のカード: 見出し「プロの目利き：」（おすすめポイントだけがある 4,140 店＝83% のカード）、札「プロの目利き」（約 330 店）、札「業界人N名推薦」。
  - 検索の概念の名前「編集部・業界人の推薦」と、フッターの導線「名古屋の業界人」。
- 「プロの目利き：」は、ホットペッパーの紹介文や機械で作った文にも付いていた。人が選んで書いた文のように読めるが、確かめた記録は無い（計画 5.5 節の決まり3）。

## 決めたこと
1. **題・説明・OGP・Twitter は、確かめられる特徴で書く。** 「広告ゼロ」（編集規約）と「シーンとエリアで探せる」（絞り込みの機能）。新しい題は「名古屋グルメ約5,000軒｜広告ゼロ、シーンとエリアで探せるガイド｜NAGOYA BITES」。「約5,000軒」は、これまでどおり `scripts/sync_store_count.js` が合わせる。構造化データの説明は、掲載と絞り込みだけを書く。
2. **トップの題を変えた前後を比べる。** 基線は GSC の 2026-09-15〜10-12 で、トップは表示 2,096・クリック 16・CTR 0.76%・平均順位 19.5。28 日後（2026-11-10 以降）に同じ集計で比べる。フォントの変更（0026）など、同じ時期の別の変更と重なるので、大きく動いたときだけ結論にし、小さな差は結論にしない。
3. **実績の帯から「現役の店長が編集」を外す**（運営者のことは「運営について」へ・計画 5.5 節）。残りは店数・広告とサクラなし・4媒体を比較の 3 項目。スマホの 2 列で最後の 1 項目が左に寄らないよう、中央に置く。
4. **店のモーダルの区画名と署名。** 「編集部の視点」→「この店のポイント」、「業界人メモ」→「知っておきたいこと」、「業界人レビュー」→「飲食業界の経験者のレビュー」（0031 の 4 と同じ・クラス名と id は変えない）。署名の「現役飲食店マネージャーが編集」は外し、根拠の語（訪問済・公開情報ベースなど）と掲載日だけを出す。どちらも無い店は、署名の行ごと出さない。
5. **店のカードの言い方。** 見出し「プロの目利き：」→「ポイント：」、「業界人メモ：」→「知っておきたいこと：」、札「プロの目利き」→「ポイント紹介」、札「業界人N名推薦」→「経験者レビューN件」。**札と見出しの位置・色・文字数は変えない。** 札「ポイント紹介」は、情報を足さない札なので、カードを作り直すとき（I-19）に外す。この課題では外さない（見た目の変更は、オーナーが前後を見てから）。
6. **検索の言い換え辞書は変えない。** `nbC('editorial', …)` の語の一覧には「業界人」「プロ」「目利き」などが残る。訪問者が検索欄に入れた語を概念に対応づけるだけで、画面には出ない。`data/selection_wording_policy.json` の `exempt` に、path・term・phrase・reason つきで 1 件だけ許す。画面に出る概念の名前は「編集部推薦・選定理由」にした。
7. **元から再生成される部分は、ここで直さない。** `index.html` の `var LOCAL_STORES`（店の紹介文と特集の題）・FEATURED の区画（特集の題）・LATEST_JOURNAL の区画（ジャーナルの題と説明）は、ビルドのたびに元（店のデータ・特集・ジャーナル）から書き直される。手で直すと次のビルドで戻る。元は P-331（特集・店のデータ）と P-332（ジャーナル）で直す。
8. **検査で止める。** `tests/selection_wording_sources.test.js` が、3 つの再生成の区画を除いたトップに、語（severity=error）が 0 件であること、題・OGP・モーダル・カードの新しい言い方、署名が空のときに行を出さないこと、を見る。

## 選ばなかった案と理由
- **札「ポイント紹介」を今外す**: 計画のカード（5.3 節）には札が無く、I-19 で外す。見た目が変わるので、オーナーが前後を見てからにする。
- **札を「おすすめ」にする**: 根拠の無い推薦に読める。無関係な推薦を避けるという方針（オーナーの制約）にも合わない。
- **辞書の「業界人」を消す**: 訪問者が入れた語を拾えなくなるだけで、画面の表現は変わらない。「業界人」を狙う語にするかは、オーナーの未決の質問のまま。
- **再生成の区画も手で直す**: 次のビルドで元から戻る。

## 見直す条件
- カードを作り直すとき（I-19）: 札「ポイント紹介」と見出し「ポイント：」を残すかを決める。
- 28 日後の GSC の比較で、トップのクリックが基線より大きく下がったとき: 題を戻すのではなく、差別化の語を入れ替えて比べる。
- 「業界人」を検索の狙い語にするかをオーナーが決めたとき: 辞書の例外を外すか残すかを決める。
