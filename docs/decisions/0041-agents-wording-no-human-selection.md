# 0041 エージェントの手引き（agents/*.md）の言い方を、人が選んだと読めない言い方にする

- 日付: 2026-10-15
- 状態: 採用
- 関連: Linear P-320（親 P-237・P-235）/ 判断の記録 0031・0032・0033 / `agents/*.md` / `data/selection_wording_policy.json` / `tests/selection_wording_sources.test.js`

## 背景
- オーナーの指示（2026-10-11）:「店舗の選定にはAIによる情報収集・分析を活用しています。人間の飲食業界関係者がすべての店舗を選定しているような表現は使用しないでください。」CLAUDE.md は PR #530 で直した。
- エージェントは手引き（`agents/*.md`）を読んで文を書くため、「業界人」「現役飲食人」「飲食業界の中の人」などが残ると、新しい文にそのまま使われるおそれがある。
- オーナーは 2026-10-13 に P-237 #2 を「推奨」と答えた（書き換える・運営者の経歴は載せない・個人名は外す）。

## 決めたこと
1. 店を選んだ・見立てた・書いた主体を人間の業界関係者とする言い方（業界人／現役飲食人／飲食業界の中の人／業界人の目利き／業界人視点のキュレーター）を、CLAUDE.md の書き方に合わせた。基準（条件）で書く・AI による情報収集・分析を活用・飲食店側の事情（席数・仕入れ・営業形態）を踏まえた根拠つきの見方・確認の記録つき。手引きとしての意味（何をすべきか）は変えない。
2. 直した箇所（ファイル別）: builder.md 1・inspector.md 2・marketer.md 2・orchestrator.md 4・strategist.md 6・editor.md 1（過去の題の引用に「新しい題には使わない」を注記）。
3. 残した例外（検索で狙う語として明示した箇所。店を選んだ主体の説明には使わない旨を注記）: marketer.md の順位表「名古屋 グルメ 業界人」、orchestrator.md の独自 KW の列挙（CLAUDE.md と同じ扱い）、strategist.md の上位 KW 例「名古屋 業界人 推薦」、editor.md の過去の題の引用。
4. 「業界人レビュワー認証制度（STR-002）」は、店の選定者でなくレビューを書く人の説明なので、「飲食業界の経験者によるレビュワー認証制度」に直した（0031 の「飲食業界の経験者のレビュー」と同じ）。
5. **`audit_selection_wording.js` の対象（公開ページ）には加えない。** 手引きは公開ページでなく、規則を引用するために語を書く必要がある（「〜と書かない」）。代わりに既存の `tests/selection_wording_sources.test.js` の CLEAN_SOURCES に、語が 1 件も無い `agents/builder.md`・`agents/inspector.md` を足し、戻らないようにした。残る 4 ファイルは上の 3 の例外があるため足さない。

## 選ばなかった案と理由
- **監査の対象に agents/ を加える**: 引用・検索語の台帳が違反として毎回数えられ、赤が常態になる（オオカミ少年化）。
- **例外の行を exempt に登録して 6 ファイルすべてを検査する**: 行の言い回しが変わるたびに登録が要り、手引きの更新が重くなる。

## 見直す条件
- 検索で狙う語（業界人 推薦 など）を残すかの決定（P-237 #2 の別項目）が出たとき、上の 3 の例外を揃えて決め直す。
- 手引きに語が戻る事故が起きたとき、exempt 方式の検査に切り替える。
