# 0085 すべての媒体で「なぜこの街（この切り口）なのか」を必須にする

- 日付: 2026-11-23
- 状態: 採用
- 関連: コミット 4b9f209baa（記事の「なぜ◯◯なのか」節・validate_journal_draft.js 項目20）/ .claude/commands/journal-today.md / docs/x-post-prompt.md / 特集・エリアページの生成と検査 / SNS分析ツールのリール・TikTok の台本の生成

## 背景
2026-11-23 本人が 11/23 の記事（今池でひとり飲みの居酒屋5選）を読んで「なぜ今池というエリアにこだわって選んだか？がないので説得力がない、読みたいと思えない」。続けて「今指摘したことを、Xやウェブサイトにも、今後作成される内容にも反映されるようにしてほしいです」。
店を並べるだけでは、読む人に「なぜ自分がこの街に行くべきか」が伝わらず、宣伝でなく判断材料を出すという名古屋バイツの方針にも合わない。

## 決めたこと
1. エリアや切り口で店を選ぶ物（記事の◯選・note・X の投稿・特集・エリアのページ・リール／TikTok の台本）は、店の紹介より前に「なぜこの街（この切り口）なのか」を置く。
2. 中身は2つ: ①その街がどんな街か（県・市・観光協会など出所のある事実。出典を示す）②なぜこのシーン・ジャンルにその街が合うか（今回の店の事実＝席・値段・駅からの近さなどで裏づける）。
3. 「人気」「定番」だけの言い切り、出所の無い他の街との比較、創作の事実は書かない。
4. 記事は検査（項目20）で落とす。X・台本は記事の節から取り、節が無ければ検査で止める。特集・エリアページは新しく作る物を必須にし、既存の物は検索流入を守るため題・URL・冒頭を変えずに節を足す。

## 見直す条件
- 節を足した記事・投稿で、読まれ方（滞在・保存・スキ）が下がったとき。
- 出所のある街の事実が見つからない街が続くとき（書き方を店の事実だけにするか考える）。
