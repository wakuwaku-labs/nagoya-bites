# 0076 成果の物差しの順序を「信頼の指標 → 記事の有用性 → 検索・利用者数」にし、読者の声を入れる

- 日付: 2026-11-17
- 状態: 採用（0007 を置き換える）
- 関連: 0069／0007（置き換え）／docs/plans/media-policy-2026-11/03-implementation-plan.md S5-5・S7-1・S7-2・S7-3／PR #762・#765／`scripts/trust_metrics.js`・`data/trust_metrics_policy.json`・`scripts/check_trust_metrics_health.js`・`.github/workflows/trust-metrics-watchdog.yml`・`scripts/recheck_due_articles.js`

## 背景
- 成果の物差しが利用者数・検索順位・記事数・店舗数で、信頼と正確さの指標が無かった（0007 の SEO 北極星4指標）。

## 決めたこと
1. 成果の第一は信頼の指標5つ（根拠確認率・未確認の明示率・誤情報の発生率・更新鮮度・独自分析の充実度）。第二に記事の有用性、第三に検索・利用者数。
2. 0007 の SEO 北極星4指標は第三位に下げる（廃止ではない）。0007 はこの ADR で置き換える。
3. 率の隣に必ず事実の文の実数を並べる。分母を減らして率を良くすることを見抜くため。
4. 悪化は「前の週との差」と「測定の停止」だけで知らせる。絶対値の下限は置かない。
5. 更新鮮度は、読者に見える確認日だけで定義する。
6. 公開後の見直し（`recheck_due_articles.js`）は既定を「記録だけ」とする。本番の自動公開の条件は 0069 決定6 のまま、本人が再承認するまで変えない。
7. 記事末尾に読者の声（役に立ったか・誤りの指摘）を置く。はい／いいえは GA4 で数え、Formspree へはコメント・誤り指摘のみ送る（無料枠 月50件を守る）。率は成果の条件にしない。再訪問率も測る。

## 結果として残ること
- 台帳が貯まるまで根拠確認率は未測定。独自分析の充実度は構造（計算式・比較表・比べる言い回し・一般則）で数える推定で、文の質は測っていない。

## 選ばなかった案と理由
- 絶対値の下限を置く → 台帳が貯まる前から鳴り続け、無視される。
- 読者の声の率を成果の条件にする → 少数の回答で動き、盛る動機になる。

## 見直す条件
- 12月15日の次の検索の計画の区切り。指標が数えられなくなったとき（見張りが知らせる）。
