# 0064 note の見出し画像は、写真の日も題と日付の帯を写真の下に足す（写真は加工しない）

- 日付: 2026-11-13
- 状態: 採用
- 関連: ADR 0056（note の見出し画像は店の実物写真）/ scripts/lib/note_eyecatch.js（makePhotoEyecatch）/ tests/note_eyecatch.test.js / Ondine #1906・#1914

## 背景
ブランドの決定（2026-11-13・本人の2択）で、写真がある日の note 見出し画像にも、記事の題と日付を付けることにした（10/23 の型）。
ただし ADR 0056 は「写真に題や文字を重ねるのは加工にあたる」として控えていた。Ondine #1914 で PR TIMES の規約を確かめたところ、改変してよいとは書かれていない（灰色）。

## 決めたこと
1. 写真は、画素もフレームも変えない。縮小・切り抜き・色の変更・文字や影の重ね描きをしない。
2. 題と日付は、写真の下に足した別の帯（地は明るい #f6f2ea・写真が無い日の図と同じ配色）に置く。画像全体は帯の分だけ縦が長くなる。
3. note の見出し画像の比率（1280:670）に合わない分は、写真を縮めずに地の余白を足して合わせる（縦長なら左右、横長なら上下）。
4. 題は語の途中で折らない（Intl.Segmenter の語単位で折り、`findWordBreaks` でも検査）。46→42→38px の順で試し、3行に収まらない・帯からはみ出すなら、写真そのままに落とす。
5. 試験: 写真の領域の全画素が元と一致すること・字が帯の外に出ないこと。
6. X の画像カード（ゴシック）と、写真が無い日の見出し画像（明るい地の図）は変えない。

## 選ばなかった案と理由
- 写真の上に暗い影と文字を重ねる（10/23 の型そのまま）: 加工にあたり、規約が灰色。
