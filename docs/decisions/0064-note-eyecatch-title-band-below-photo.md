# 0064 note の見出し画像は、写真の日も題と日付の帯を写真の下に足す（写真は加工しない）

- 日付: 2026-11-13
- 状態: 採用
- 関連: ADR 0056（note の見出し画像は店の実物写真）/ scripts/lib/note_eyecatch.js（makePhotoEyecatch）/ tests/note_eyecatch.test.js / Ondine #1906・#1914

## 背景
ブランドの決定（2026-11-13・本人の2択）で、写真がある日の note 見出し画像にも、記事の題と日付を付けることにした（10/23 の型）。
ただし ADR 0056 は「写真に題や文字を重ねるのは加工にあたる」として控えていた。Ondine #1914 で PR TIMES の規約を確かめたところ、改変してよいとは書かれていない（灰色）。

## 決めたこと
1. 写真は、画素もフレームも変えない。縮小・切り抜き・色の変更・文字や影の重ね描きをしない。
2. 題と日付は、写真の下に足した別の帯（地は明るい #f6f2ea・写真が無い日の図と同じ配色）に置く。帯の高さは全体の約26%、写真の上の余白は約5%。日付は31u・ラベルは28u（u = 全体の幅/1280。400px 幅に縮めても読める大きさ）。
3. 全体は note の見出し画像の比率（1280:670）。残りは左右の余白で、写真は中央に置く（左右の余白は上より広くなる。写真と帯を足すと比率の都合で避けられない）。
3a. 写真の幅が全体の60%を切る日（4:3・正方形・縦長など）は、帯を付けず写真だけを見出し画像にする（2026-11-13 見た目の検査での修正）。
4. 題は語の途中で折らない（Intl.Segmenter の語単位で折り、`findWordBreaks` でも検査）。34→32→30u の順で試し、2行に収まらない・帯からはみ出すなら、写真そのままに落とす。
5. 試験: 写真の領域の全画素が元と一致すること・字が帯の外に出ないこと。
6. X の画像カード（ゴシック）と、写真が無い日の見出し画像（明るい地の図）は変えない。

3b. 下限を65%から60%に下げた（2026-11-13）: いちばん多い 16:9 の写真は幅の割合が約64%で、65%だと帯が付かないため。比率は崩さず、写真は縮めない。4:3・正方形・4:5 は60%未満なので写真だけのまま。左右の余白が上より広いのは、この形では避けられないので許容する。

## 選ばなかった案と理由
- 写真の上に暗い影と文字を重ねる（10/23 の型そのまま）: 加工にあたり、規約が灰色。
