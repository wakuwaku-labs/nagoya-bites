# 0007 SEO の成否を北極星指標4つで判定し、GA4 の真値が出るまで PV を比べない

- 日付: 2026-10-09
- 状態: 採用
- 関連: SEO-115（GA4 修復）/ SEO-116（90日計画の親）/ SEO-043（判定基準）/ SEO-090 / `docs/seo-strategy-2026-10.md` / `data/gsc_metrics.json` / `data/search_channel_metrics.json`

## 背景
- 店舗ページ 5,008 本で GA4 のインライン script が構文エラーになり、2026-05-08 の生成分から動いていなかった（SEO-115 で修正）。GA4 の PV・回遊・CTA 率は店舗ページ分を欠いたまま判断されてきた
- `docs/growth-plan-2026-q4.md` のチェックポイントは 30日PV で判定していた。10-15 の 4,000PV は未達が確定（1,770）
- クエリが分かる Google の表示（全体の 45.9%）の 6 割は店名指名検索で、総クリックはその増減に引きずられる（SEO-043）
- 検索流入は Bing 28.0% / Google 26.7% / Yahoo! 11.3% / 生成AI 7.4%。GSC は Google の分しか映さない

## 決めたこと
1. SEO の成否は次の 4 つで判定する。出典は括弧内のファイルに限る（制約10）
   - 発見型の表示とクリック（`gsc_metrics.json` `intent.kpi`）
   - 表示が出たハブの数とハブの表示（`gsc_metrics.json` `pageTypes.area_hub`）
   - 生成AI 経由のセッション（`search_channel_metrics.json` `engines`）
   - Bing 経由のセッション（同上）
2. 総クリックは判定に使わない。PV と GA4 の回遊・CTA 率は、SEO-115 の合流後に真値で基線を取り直す（SEO-118・10-20）まで前後比較に使わない
3. チェックポイントは 10-15 / 10-20 / 11-15 / 11-30 / 12-15 とし、到達条件と未達時の打ち手は `docs/seo-strategy-2026-10.md` §4 を正本にする
4. エリア×ジャンル×条件ページは 11-15 まで大量に noindex しない。11-15 に、条件ページのうち (i) 掲載 15 軒未満 (ii) 親ジャンルページの上位 60 店との重複 80% 以上 (iii) 公開 60 日で GSC 表示 0 のどれかに当たるものを noindex,follow にし sitemap から外す。削除はせず、内部リンクは残す（SEO-126）
5. やらないこと: 接待・個室特集の 7 本目と忘年会の新規特集、FAQPage とサイトリンク検索ボックスの構造化データへの投資、条件ページの追加量産、店舗ページの一括 noindex、店名指名検索の 1 位争い、Yahoo! 個別の施策
6. 忘年会は既存の `features/banquet.html` の強化だけ行い、11-30 に「忘年会」「宴会」を含む検索の表示が 50 未満なら撤退する（SEO-141）

## 選ばなかった案と理由
- 30日PV の目標を据え置く: 店舗ページ分が計測されていない数字で判定することになる
- 総クリックで判定する: 店名指名検索の増減と混ざり、施策の効果が分離できない（SEO-043）
- ハブを今すぐ大量に noindex する: 本番 sitemap に安定して載ったのが 09-28 からで、評価に 2〜3 か月かかる前提では判断材料が無い
- 接待・宴会の特集を増やす: 6 本で 26 表示・0 クリックの実測があり、需要が観測されていない（SEO-090）

## 見直す条件
- 12-15 のチェックポイントで 2027-Q1 の計画を作るとき
- GA4 の真値の基線が取れ、PV を判定に戻せると確認できたとき
- Google が発見型の検索面で大きな仕様変更（AI モードの既定化など）を行ったとき
