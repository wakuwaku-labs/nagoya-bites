# 0072 トップの最初の画面を、理念・このサイトの約束・3分類の新しい記事にする（店の検索は2番目・店数の主張は看板から外す）

- 日付: 2026-11-17
- 状態: 採用
- 関連: 0069 決定2（本人 2026-11-16「決定2: A」）／置き換える決定 0035・0032・0039・0021（トップの設計と店数の書き方）／docs/plans/media-policy-2026-11/03-implementation-plan.md S6-1／`index.html`／`scripts/build_journal_index.js`／`scripts/lib/store_count.js`／`tests/top_articles_first.test.js`／Ondine #2044

## 背景
- 新しい基本方針の理念は「飲食店選びの失敗を、情報の力で減らす。」。記事が主、店のデータは記事の根拠を支える土台。
- 旧トップは店を探す場所として設計されていた（題「名古屋グルメ約5,000軒｜広告ゼロ、シーンとエリアで探せるガイド」・最初の画面は検索窓と話題店・特集は画面の外）。理念と「減らす失敗」はどこにも書かれていなかった。トップの検索クリックは28日で10件（平均39位）で、トップは検索エンジンからの入口として小さい。

## 決めたこと
1. 題・大見出し・説明・OGP を理念に合わせる。採用した題は「名古屋の飲食店選びの失敗を、情報の力で減らす｜NAGOYA BITES」、大見出しは「飲食店選びの失敗を、情報の力で減らす。」（上に「名古屋の飲食店ガイド」）。ほかの2案（B・C）は PR に画像つきで残し、本人が選び直せる。題を変えても `data/measurement_changes.json` に日付を残し、前後比較の基線を分ける。
2. 最初の画面を「理念 → このサイトの約束 → 3分類の新しい記事 → 店の検索・シーンとエリアの入口」の順にする。広い画面では右の列に「新しい記事 → 今日の話題店」を置き、左の列に検索を収める。
   - 約束は編集規約（features/editorial-policy.html）に書いてあることだけを3行で: 広告費・掲載料を受け取らない／出典・日付を残し不確かな記述は取り下げる／AIが集めて書き検査している（人が店で確かめた記事ではない）。実態より強い約束は書かない（約束が実態を追い越さない・S6-2）。
   - 3分類の新しい記事は、`scripts/lib/journal_category.js` の分類（話題のお店紹介・店選びガイド・比較・特集）ごとの最新1本。`scripts/build_journal_index.js` が `TOP_ARTICLES` の目印の間に静的に書く（build.js から毎日回る）。空の分類は行を出さない。写真は載せない（最初の画面を軽く保つ）。
3. 店の検索は2番目に残す。検索窓は1画面目（スマホ 390×844）の下端、固定の検索バーより上に完全に見える。検索・絞り込み中は約束と記事を畳む（既存の search-active の規則に足した）。機能は変えない。
4. 店数の主張を看板から外す。題・説明・OGP・構造化データの説明から「約5,000軒」を除き、権威性バー（「5,000店／広告なし・掲載料なし／4媒体を比較」）を廃止する。`scripts/sync_store_count.js` の index 範囲は `authTotal` を外した（本文に「約N軒」が戻れば従来どおり追随する）。店数は一覧・内訳・統計では引き続き出せる（0021 のうち「サイト全体の掲載数は丸めて書く」は、トップの看板では使わない）。

## 置き換えるもの
- 0035（トップの最初の画面は写真で選べる店の行）: 話題店の行は残すが、最初の画面の主役ではなく、検索のあと（広い画面は右の列で記事の下）に下げる。
- 0032（トップの題・説明の言い方）: 「広告ゼロ、シーンとエリアで探せる」を看板にする部分を置き換え。人が選んだと読めない言い方を使う原則は残す。
- 0039（トップの設計）: 全店の索引の置き換えは変えない。トップは店を探す場所、という位置づけだけを置き換える。
- 0021（店数の表記）: トップの看板での店数の主張をやめる。

## 選ばなかった案と理由
- 検索窓を最初の画面から外す: 店を探しに来た人が迷う。下端に残して、計測で検索の利用が減りすぎたら位置を戻す。
- 約束を長い文にする: 最初の画面の高さを食い、検索窓が押し出される。詳細は編集規約へのリンクに任せる。
- 下の「編集の約束」の帯・最新ジャーナルの3件を消す: 計画の範囲外。重複は PR に書き、本人が決める。

## 見直す条件
- 公開後28日で、トップの検索の利用（search・filter_apply）が前の28日より大きく減ったら、検索窓の位置を戻す。
- トップの検索流入（GSC）が半減したら、題を戻すか B・C 案に替える。
