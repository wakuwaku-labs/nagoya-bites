# 0082 X は長いポスト（X プレミアム ベーシック）で出し、断られたらスレッドに戻す

- 日付: 2026-11-23
- 決めた人: 本人（「もっと長く・1つのスレッドに」→ 選択「ベーシックにします」）

## 背景

- 2026-11-23 本人「Nagoya Bites の X が見にくい」→ 文面を改行・「・」・【】「」（）で見やすくした（同日の別コミット）。
- 続けて「もっと長くすることはできないの？一つのスレッドに」。料金と方法を調べて示し、本人がサブスクを選んだ。
- X 公式（https://help.x.com/ja/using-x/x-premium・2026-11-23 確認）: ベーシックは日本で月368円（Web）。全プランで「長いポスト」（最大25,000字）が使える。「記事」機能はプレミアムプラスだけ。
- X API の Create Post の仕様（https://docs.x.com/x-api/posts/create-post）は「text は X Premium のアカウントでなければ280字まで」。一方で開発者フォーラムには、プレミアムでも API から長文が断られたという報告がある。実際に通るかは契約後の初回で分かる。

## 決めたこと

- `data/x_post_policy.json` の `longPost.enabled=true`。保存した文面の本文と続き（最大 `maxSections`=5 件）を、空行で区切って1つの長いポストにまとめて先に送る。URL・ハッシュタグ・写真のクレジットは最後。
- 断られたら（未契約・API が受け付けない等）、今までどおり本文＋返信3件のスレッドで送り直す。台帳の `long_post`（tried・ok・reason）に残す。重複の拒否なら送り直さない。通信の失敗は届いたか分からないので、送り直さずに失敗として扱う。
- スレッドなしの実験（x-nb-thread-vs-single）の日は、続きを書かせないので長いポストにもならない。
- SNS分析ツールは、`long_post.ok` の投稿を「続きあり」と数える。先頭の文字数は `long_post.head`（見えている本文）で数える。

## 費用

- サブスク: 月368円（本人が契約）。
- X API: 長いポストは1回の投稿なので、URL つき 0.20 ドルだけで済む。返信3件分（0.045 ドル）が要らなくなる。断られた日は、スレッドの分が今までどおりかかる。

## 戻し方

- `longPost.enabled=false` にすれば、今までどおり本文＋返信のスレッドに戻る。
