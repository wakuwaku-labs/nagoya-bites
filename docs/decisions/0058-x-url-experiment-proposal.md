# 0058 X の投稿で「本文にリンクを入れる日／入れない日」を比べる実験（0055 の3の改定案）

- 日付: 2026-11-07
- 状態: 採用（2026-11-07 本人承認、期間2週間: 2026-11-08〜2026-11-21 JST）。期間の外は自動でオフに戻り、0055 の3（リンクは本文に残す）に戻る。期間は当初案の8週間から2週間に短縮された
- 関連: docs/decisions/0055-sns-reach-practices.md（3. X のリンクは本文に残す）/ data/x_post_policy.json の `urlExperiment` / scripts/lib/x_post.js（`urlVariantFor`・`stripUrl`・`validatePost` の `allowNoUrl`）/ Ondine #1601 / 実装指示書 x-growth-implementation-brief.md 段階F

## 背景
- 0055 の3は「リンクは本文に残す」と決めた。根拠は、リンクの減点は撤廃済みで、返信に移しても費用が同じ（URL 付きの投稿は 0.200 ドル／回）ことだった。
- ただし 24 件すべてが URL 付きで、URL なしの投稿が 0 件のため、リンクの有無が表示数・反応・サイト流入にどう効くかを自分たちのデータでは比べられない。X の表示は 1 桁〜十数回が続いている。
- 公式の料金表では URL 付きの投稿だけ単価が高い（0.200 ドル。URL なしは 0.015 ドル）。URL なしの日が増えれば X の費用も下がる。実際の請求単価は Developer Console で未確認。

## 決めたいこと（承認してほしい内容）
1. 一定期間、日付から機械的に決まる割り当てで、本文にリンクを入れない日（`no_url`）を混ぜ、入れる日（`url`）と比べる。既定は半々（`noUrlShare: 0.5`）、期間は 2 週間（承認時に 8 週間から短縮。`since` 2026-11-08〜`until` 2026-11-21）。
2. `no_url` の日も、数字は記事にあるものだけ・言い方の検査・重複・文字数・スレッドの続きなど、URL 以外の検査はすべて通す。記事へのリンクは外すだけで、ほかの記事のリンクを入れることはしない。
3. 割り当ては「日付＋実験 ID」のハッシュで決まるので、再実行・やり直しでも同じ日は同じ。二重投稿防止（台帳の slug）と失敗時の動きは変えない。
4. 台帳 data/x_post_log.json の各行に `experiment`・`url_variant` を足す（実験オフの間は足さない）。
5. 比べる指標は、投稿の表示回数・ブックマーク・リポスト（data/x_metrics.json）。サイト流入は投稿ごとには測れていない（媒体ごとの 30 日合計だけ）ので、この実験の判定には使わない。
6. 判定の目安: 各群 10 本以上たまるまで結論を出さない。それまでは「判定不可」と書く。止める条件: `no_url` の日の表示回数の中央値が `url` の日の半分以下の状態が 3 週続いたら、本人に報告して実験を止める（`enabled: false` に戻すだけ）。

## 戻し方
`data/x_post_policy.json` の `urlExperiment.enabled` を `false` に戻す 1 行（コードの revert は不要）。台帳に足した `experiment`・`url_variant` は残しても既存の読み手は無視する。

## 選ばなかった案と理由
- 返信にリンクを移す実験: 0055 で費用が同じ・リンクカードが消えると整理済みで、「リンクなし」より情報が増えない。
- 週ごとに切り替える: 曜日の差と混ざって比べにくい。日ごとの割り当てなら曜日にも散る。
- 最初から全部 URL なしにする: サイトへの流入を測る手段（utm_source=x）が失われ、戻せる実験にならない。
