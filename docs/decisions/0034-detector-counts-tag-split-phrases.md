# 0034 検査が、強調・改行などのタグで割れた言い回しも数える（トップの最初の画面の見出しを直す）

- 日付: 2026-10-14
- 状態: 採用
- 関連: Linear P-389（親 P-235・UI・UX全面改修）・P-390（公開されている docs/ の扱い）/ P-330（トップの言い方）・P-332（ジャーナル）・P-334（題の系統） / 判断の記録 0032・0033 / `index.html` / `scripts/audit_selection_wording.js` / `tests/selection_wording_inline_tags.test.js` / `tests/selection_wording_sources.test.js` / `data/selection_wording_policy.json`

## 背景
- オーナーの指示（2026-10-11）:「店舗の選定にはAIによる情報収集・分析を活用しています。人間の飲食業界関係者がすべての店舗を選定しているような表現は使用しないでください。」
- 2026-10-14、トップの作り直し（計画の段階 3）の下調べで、トップの最初の画面の見出し（`index.html` の `<h1>`）が、直したはずの言い回しのまま本番に出ていると分かった。

  ```
  <h1>飲食の<em>プロ</em>が、<br>名古屋<em>だけ</em>を<br><span class="fade">深く選んだ。</span></h1>
  ```

  人が選んだと読める。P-330（#546）の本文には「→名古屋の飲食店を、確かめられる情報で選ぶ。」と書いてあったのに、PR では直っておらず、達成条件の「検査の語が 0 件」は満たされて見えていた。
- 原因は検査器だった。語の一覧を「タグのついた文字列」に当てていたため、`飲食の<em>プロ</em>が` のように、強調・改行・リンクのタグで語が割れていると当たらない。0 件は「問題が無い」ではなく「検査器が見えていない箇所を除いて 0 件」だった。
- 公開ページ 6,137 本を、タグを外した文字列にも語を当てて調べ直した。タグで割れた言い回しは、この 1 か所（`inshoku-pro`）だけだった（特集・ジャーナル・店舗・エリアのページに、ほかの割れは無い）。
- 同じ文は `docs/instagram-launch-kit.md`（Instagram のプロフィール文の 3 案）にもある。HTML 以外の公開ファイルにも検査の語が多数あり（docs/ 140・data/ 117 ほか）、扱いはオーナーの判断になる（P-390）。

## 決めたこと
1. **トップの見出しを直す。** 「名古屋の店を、／確かめられる／情報で選ぶ。」（3 行）。「確かめられる情報」は、運営についてと編集規約の説明と同じ意味（0031）: AIが集めた情報を、出どころのわかるデータ（ホットペッパーグルメ・Google の店舗情報・報道やメディアの記事）と突き合わせてから載せる。オーナーの文（店舗の選定にはAIによる情報収集・分析を活用）と食い違わない。
   - 1 行は 7 字以内にする。スマホの文字の大きさは `clamp(2.4rem, 9vw, 4rem)` で、最小の 38.4px では 7 字で約 269px。画面の幅 320px から左右の余白 38px を引いた 282px に収まる。8 字だと折り返す。
   - 強調（`<em>`）と薄い色（`.fade`）の使い方は、これまでの見出しと同じ。
2. **検査器を直す（`scripts/audit_selection_wording.js`）。** タグを外した文字列にも同じ語の一覧を当て、元の文字列でタグをまたぐ一致だけを足す（タグをまたがない一致は二重に数えない）。
   - 外すのは、文の途中に入るインラインのタグだけ: `em strong b i u s span a mark small sub sup abbr cite code del ins font ruby rt rb br wbr`。`<br>` は、見た目の折り返しで語が割れる（`飲食の<br>プロ`）ので外す。
   - 段落・見出し・リスト項目などの境目（ブロックのタグ）は外さない。別の文の端どうしをつないで数えない（`<li>業界</li><li>人気店</li>` は 0 件）。
   - 作業の一覧に出す前後の文は、これまでどおりタグを除いた読める形（`【飲食のプロ】が、深く選んだ。`）。
3. **検査で止める。** `tests/selection_wording_inline_tags.test.js`（9 件）が、割れた言い回しを数えること・二重に数えないこと・ブロックの境目をつながないこと・属性（代替文）・語が無い文は 0 件のこと・直す前のトップの見出しは数え、今の見出しは数えないことを見る。古い検査器に戻すと 9 件中 6 件が落ちることを確かめた。`tests/selection_wording_sources.test.js` に、トップの見出しが 3 行・各行 7 字以内であることを足した。
4. **数字。** `node scripts/audit_selection_wording.js` のサイト全体は、古い検査器で 470 ページ・1,216 か所 → 新しい検査器で見出しを直す前は 1,217 か所（この見出しの 1 件）→ 見出しを直した後は 1,216 か所。夜間 QA の数字が動かないのは、新しく見つけた 1 件を同じ変更で直したため。トップの残り 9 か所は、元から再生成される特集の区画（FEATURED）の題で、題の系統として P-334 が扱う。

## 選ばなかった案と理由
- **語の一覧のほうを、タグが挟まっても当たる形に書き直す**（例: `飲食(?:<[^>]*>)*の?(?:<[^>]*>)*プロ`）: 語ごとに全部書き直しが要り、一覧が読みにくくなる。語を足すたびにタグの挟まり方を考えることになる。タグを外して当てるほうが 1 か所で済む。
- **ブロックのタグも外す**: 別の段落・項目の端どうしをつないで数え、誤検知になる。
- **見出しを題の系統として P-334 に持ち越す**: 人が選んだと読める主張を、少なくとも 2026-11-10 まで（4 週間）、最初の画面の一番上に出し続けることになる。h1 は検索結果に出る題（`<title>`）ではない。トップの題の前後比較（0032 の 2）への混ざりは、0032 の読み方（大きく動いたときだけ結論にする）で扱える。信頼を損なう主張を残すほうが重い。
- **見出しを「飲食の経験を持つ人が…」のような別の主張にする**: 確かめられない。
- **`docs/instagram-launch-kit.md` も同じ変更で直す**: すでに外の媒体（Instagram のプロフィール）に出ている文と合わせる判断が要る。公開されている docs/ の販促文の扱いとあわせて、オーナーが決める（P-390）。
