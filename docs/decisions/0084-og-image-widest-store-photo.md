# 0084 記事のリンク画像（og:image）は、記事の店のいちばん大きいホットペッパー写真にする

- 日付: 2026-11-23
- 状態: 採用
- 関連: ADR 0078（ホットペッパー写真の大きさ違いの URL）/ ADR 0082（X の長いポスト）/ scripts/lib/og_photo_pick.js / scripts/generate_daily_draft.js（pickWidestOgPhoto）/ tests/og_photo_pick.test.js

## 背景
2026-11-23 本人「もっと画質の良く見える写真を使えないの」。X の投稿の写真は、記事の og:image から X が作るリンクカード（大きい画像）。
11/23 の記事の og:image は主役の店の写真のサフィックス無し版で 358px しかなく（同じ写真の _480 版は 480px）、カードがぼやけていた。記事の別の店には 1280px の写真があった。11/11 の記事も 182px だった。

## 決めたこと
1. og:image がホットペッパーの写真なら、同じ写真の大きさ違い（_480 とサフィックス無し）のうち広い方にする。幅は data/hotpepper_photo_sizes.json、無ければ記事を作るときに測って足す。
2. それでも 640px 未満なら、記事に載せた店（input.stores）のホットペッパー写真から、いちばん広いものに替える。
3. ただし題に店の名前（または名前の最初の語）が入る記事は、別の店の写真に替えない（1店が主役の記事のカードに別の店を出さない）。
4. どれも URL を参照するだけ（加工・自ホストなし）。X に写真を直接上げない（ホットペッパーの規約・ADR 0062）。生成画像・ストック写真は使わない（CLAUDE.md 制約9）。
5. 既存の記事は 11/08〜11/23 を同じ選び方で見直し、11/23（別の店の 1280px）と 11/11（同じ写真の 480px）を直した。

## 見直す条件
- 店の写真がどれも 640px 未満の日が続くとき（プレス写真の日を増やすなど別の手を考える）。
