## 記入ルール（必読）

- **捏造禁止**: 自分が知らない店は空欄でスキップ。AI に書かせない。
- **業界人視点**: 一般のグルメライターには書けない「なぜこの店が良いか」の裏側（仕入れ・人・運営・差別化）を 60〜120 字程度で。
- **insiderNote**: より具体的な内部情報（オーナー経歴・調達ルート・予約困難の理由・業界人が頼むメニュー等）を入れたい場合。空欄可。
- **visitStatus**: `visited` / `recommended_by_peer` / `industry_known` のいずれか。空欄なら `industry_known` 扱い。

## 記入後の取り込み手順

2. `node scripts/import_editorreason_todo.js` で `data/editor_picks.json` に反映
