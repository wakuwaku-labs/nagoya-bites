このページは、私たち編集部が NAGOYA BITES を運営するにあたって守っていることを、読者のみなさんに公開するためのものです。

運営は個人で、AIを使いながら行っています。氏名・経歴・所属は公開していません（理由は05に書きました）。

代わりに、どう選び、どう書いているかを、実際の手順のとおりに書きます。

01 — Editorial Principles

NAGOYA BITES の編集方針は、何を載せるか・何を載せないか・どう書くかの三本柱で成り立っています。 この三つが噛み合って初めて、他のグルメメディアと違うものを届けられると考えています。

I
What We Publish
何を載せるか
  • 名古屋・愛知に限定する
  • 決めた条件とデータで選ぶ（手順は 02 に公開）
  • 複数の情報源（ホットペッパーグルメの掲載情報・Google の評価と口コミ件数・他のメディアでの掲載・報道）をAIで集め、突き合わせて判断する
II
What We Exclude
何を載せないか
  • 掲載料を受け取った店は載せない
  • 広告費や好みで、載せる店や順位を変えることはしない
  • 閉店や営業実態が確認できない店は載せない
III
How We Write
どう書くか
  • 客として見える表面だけでなく、席数・回転・価格設計・オペレーションなど、公開されている情報から読み取れることまで書く
  • シーン別の使い方まで踏み込む
  • 必要に応じて「選ばなかった理由」も書く

02 — Selection Criteria

店舗の選定にはAIによる情報収集・分析を活用しています。 一つの指標だけで判断せず、複数の情報をつき合わせています。実際の手順は次のとおりです。

掲載基準と選び方の手順

  • 名古屋・愛知の飲食店だけを載せる。愛知県外の店は取り込みません。
  • 情報はAIで集め、出どころのわかるデータと突き合わせる。店舗の基本情報はホットペッパーグルメ Web サービスから毎日自動で更新し、休業・移転などの変化を速やかに反映します。★と口コミ件数は Google の店舗情報から取ります。新しい店や話題の店は、報道やメディアの記事をAIが探し、出典の URL とともに候補に入れます。
  • 実在を確かめる。手動で加える店は、Google の店舗情報で店名・住所・業態を照らし、確認できない店は載せません。載せたあとも、ホットペッパーの掲載終了や閉店の表示などを照らし、閉店と確かめた店は外します。
  • Google の評価はそのまま載せ、参考度を併記する。★と件数に手を加えず、直近の口コミの傾向などから「口コミ信頼度」を機械的に出します（04-D）。
  • 特集に載せる店は、条件と点数で決める。テーマごとの条件（例: 価格の表示がある・Google の評価が一定以上）で絞り、点数をつけて選びます。多くの特集は毎月、掲載店を組み替えています。点数の中身と、特集の番号の意味は 07 に書きました。
  • 選定理由を添える店には、根拠の語を付ける。「訪問済」は編集部が実際に訪れた店、「公開情報ベース」は公開されている情報をもとに書いた店、「公開情報ベース（自動収集）」はAIが集めた公開情報を運営者が確認して載せた店です。

03 — Independence

お金の流れを開示することは、編集の信頼性を担保するうえで最低限の約束です。 現在および将来にわたって、次のルールを守ります。

金銭関係と広告の扱い

  • 掲載料・PR 費は受け取らない。店舗から金銭を受け取って掲載・優遇する広告モデルは採用していません。予約リンクからの成果報酬も受け取っていません。
  • 将来広告を入れる場合でも、記事と広告を視覚的に分離し、タイアップ記事には必ず明示ラベルを付けます。
  • 実地取材を行う場合、食事代は原則編集部が負担。店側の招待を受けた場合は記事にその旨を明記します。

03-B — 収益と編集の分離

NAGOYA BITES は持続可能なメディアであるために、将来的に収益事業を持つ可能性があります。 ただし、いかなる収益も「どの店を載せるか・どの順に見せるか・どう評価するか」には一切影響させません。 編集の独立は、収益より常に上位の原則です。

収益事業と編集判断の分離ルール

  • 店選びの相談・提案（接待・宴会コンシェルジュ等）は、特定店からの送客手数料を目的にしません。提案は読者の利益だけを基準に、中立な立場で行います。
  • 店舗側から費用をいただく場合があっても、それは掲載順位・選定・評価に影響しない実費型に限ります（例：オーナーによる情報更新、取材実費など）。「良く書く対価」は受け取りません。
  • 予約・物販などのリンクから収益は得ていません。将来収益が発生する場合でも、リンクの有無による掲載の優遇は行わず、掲載基準は収益と完全に独立して決めます。
  • 広告・PR 記事・有料の上位表示枠は引き続き設けません。編集独立性が当サイト最大の価値であり、これを毀損する収益は採用しません。

04 — Trust Mechanisms

飲食業界の広告媒体には、金銭授受や無償提供と引き換えに書かれた口コミ・PR 記事・SNS 投稿（いわゆる「桜」）が数多く混じっています。 消費者が安心して店を選べる場をつくるために、NAGOYA BITES は桜が混じれない構造と、嘘がついても発覚する構造を併用します。

A
Structure
構造で防ぐ
  • 掲載料・PR 費は受け取らない
  • レビュワーが店舗から金銭・無償提供を受けることを禁止
  • 違反時は永久追放
B
Disclosure
受け取った場合は必ず開示
  • 金銭・無償提供の有無を必須申告
  • 店舗との関係性を 7 択から必ず選択
  • 訪問日を必須記載
  • レビュワーごとの投稿履歴を公開
C
Verification
嘘がバレる仕組み
  • 飲食業界の経験者によるレビュワー認証（経歴・ハンドル公開）
  • 店舗側からの異議申立て窓口
  • 読者からの通報窓口
  • 編集部によるファクトチェック

04-D — Cross-Check Integrity（機械統計レイヤー）

上記 A / B / C の 3 本柱に加え、サイト上の各店舗に対して「この店の Google の★と件数は、そのまま信じてよいか」に答える「口コミ信頼度」（SS〜Dの5段階・0〜100）を機械的に算出する仕組みを運用しています。 Google Places API（★・件数・最新 5 件の★と投稿日）/ Hot Pepper API / 他メディア掲載履歴 — 取得可能な公式 API と既に編集部が確認しているデータだけを使い、 食べログ・Retty 等の口コミ本文は一切取得せず、件数・★と件数のバランス・直近の口コミの傾向・評価の分布・第三者メディアの掲載という検証項目のうち観測できたものだけで採点します。当サイト側のデータ整備状況（タグや Instagram の有無）は口コミ信頼度に含めません。

重要なのは、これを「サクラ確率」とは呼ばないことです。誤判定で誠実な店を傷つけるリスクがあるため、機械統計を借りながらも個別店を「サクラ」と名指しする表現は採用しません。 段階の語は店への評価ではなく読者への助言（SS「文句なしに参考にできます」〜 D「他の情報と合わせて判断を」）で、内訳には観測事実だけを書きます。段階の低い店にも同じ形で表示し、非表示にはしません（2026-08-20 改訂）。 算出ロジック・検証項目・計算式・異議申立て窓口のすべてを公開しています。

仕組みの全公開（第三者検証可能）

  • 口コミ信頼度の読み方（1 分）／ 口コミ信頼度の作り方（方法論） — 検証項目の定義・計算式・段階表示・戦わない領域・異議申立て窓口を完全公開
  • 実装は公開リポジトリ wakuwaku-labs/nagoya-bites の scripts/lib/cross_check.js（採点）と scripts/lib/trust_display.js（段階への変換・基準は data/trust_display_policy.json）で第三者再現可能
  • 誤判定が疑われる場合は editor@nagoya-bites.com 宛にメール — 10 営業日以内に一次回答

レビュワー必須申告事項

  • 訪問日を必ず記載すること。
  • 店舗との関係性を以下の 7 択から必ず 1 つ選ぶこと（自由記述は不可）。
    1. 無関係（一般客として訪問）
    2. 家族・親族
    3. 友人・知人
    4. 取引先・業界関係者
    5. 店舗関係者（オーナー・スタッフ・元スタッフ）
    6. 招待客（店から無償招待・無償提供を受けた）
    7. PR 案件（金銭授受あり）
  • 選択肢 4〜7 を選んだ場合、記事内に該当ラベル（例：「招待客レビュー」「PR 案件」）を目立つ形で必ず併記。ラベル無しの掲載は規約違反とする。
  • 金銭・無償提供の有無は、選択肢の選定時点で開示済みとみなす。受領内容に変更があれば即時更新。
  • ※ 支払い金額の記載は求めない。プライバシーへの配慮および検証コストの観点から、訪問日と関係性で十分な開示水準とする。

違反が発覚した場合のペナルティ

  • 該当レビューを即時削除する。
  • 違反した寄稿者・レビュワーは永久追放とし、再登録は認めない。
  • 透明性を保つため、違反事実をサイト内で公表する（個人を特定しうる情報は伏せる）。
  • 当該店舗が違反に関与していた場合、編集部の判断で掲載を見直す場合がある。

異議申立て・通報窓口

  • 店舗側からの異議申立て：「このレビューには事実誤認がある」「利害関係が開示されていない」等の申し立ては editor@nagoya-bites.com 宛に。
  • 読者からの通報：「このレビューは桜ではないか」と感じた場合も同窓口へ。匿名通報を歓迎します。
  • 受け付けた申立て・通報はすべて編集部内で記録し、10 営業日以内に一次回答します。

飲食業界の経験者向けのレビュワー認証制度に応募したい方は、 レビュワー募集ページから募集要項・必須義務・認証フローをご確認ください。

05 — Why Anonymous

「運営しているのは誰なのか」—— よく聞かれる問いに、きちんと答えます。

NAGOYA BITES は個人で運営しています。氏名・経歴・所属は公開していません。 特定の店との個人的な関係や利害が、掲載や評価に影響しないようにするためです。 「あの店の悪口は書きにくい」「お世話になった方のお店は持ち上げてしまう」—— そうした偏りが入り込む余地を、最初から作らないことを選びました。

匿名にしているのは、隠したいからではなく、書きにくい店もきちんと書ける状態を維持するためです。 そのかわり、判断の根拠は運営者の肩書きではなく、確かめられる情報に置いています。 選び方（02）・お金の流れ（03）・口コミ信頼度の計算（04-D）は、このページとリンク先ですべて公開しています。

編集部の構成（役割のみ開示）

  • 運営者（個人）選び方の基準を決め、問い合わせや指摘に対応する。AIが集めた情報の一部（選定理由など）は、確認してから載せる
  • AIエージェント（データ収集・突き合わせ・下書き作成）店舗データの収集・整合性チェック・記事下書きの生成を担当。公開前は、実在・出典・写真の出どころなど、決めた検査を通ったものだけを公開する

※ 「編集部」は、運営者とAIエージェントを合わせた呼び名です。氏名・経歴・所属は公開していません。

06 — How We Read

集めた情報は、そのまま並べるだけでなく、飲食店の仕組み（席数・回転・価格設計・営業時間・仕入れなど）の面から読み解いて書くことがあります。 他のメディア・Google の評価・店舗写真・SNS の投稿など、誰でも見られる情報をもとにするので、書いた内容は出典から確かめられます。

たとえば一枚の店内写真からカウンターの深さや厨房の動線を読み、店のつくりを考える。 営業時間と席数から「狙い目の時間帯」を割り出す。 複数のメディアで評価が割れている店について、 「なぜ割れているのか」を営業のしかたの違いから説明する—— そうした読み解きの厚みを、これから記事に積み上げていきます。 推察は推察とわかるように書き、事実とは混ぜません。

今後の記事で扱うトピック例

  • 店舗写真から厨房構造・カウンター深さ・動線を読み、店のつくりを考える
  • 業態転換の履歴とその意味（なぜその時期に方向転換したのか）
  • シフト帯と時間帯別の狙い目（店内写真と営業時間から推定する）
  • 同業態での細部比較（味噌煮込みうどんの麺加水率、味噌配合などの違いを解説）
  • 複数メディアの評価が割れる店の「なぜ割れているか」を、営業のしかたの違いから説明する
  • シーン別の使い分けで押さえるべき運用の実態

07 — The Courage to Decline

「選ばない勇気」も編集の仕事です。 約5,000軒のデータベースを持っているからこそ、 「どの店を外すか」の判断に編集部の姿勢が表れると考えています。

a) 「良い順」の総合ランキングは作らない

点数だけの順位は文脈を取りこぼします。「誰と・どんなシーンで・どんな気分で」を無視した順位付けは、読者を間違った選択に導きかねません。NAGOYA BITES は、全店を 1 つの物差しで「良い順」に並べた総合ランキングの記事を作りません。

ただし、数字で並べている面はあります。特集の 01・02… の番号は、掲載の順番です。毎月掲載店を組み替えている特集では、点数の高い店を先に、その月に入れ替える店を後に並べ、どちらの中も点数の高い順です。点数は、Google の評価、口コミの数、口コミや営業の実態を検証した点数、話題性に、その特集のシーンや条件への合い方を加えたもので、話題の店、「編集部推薦」の印がある店、その月の季節に合う店には加点があります（同じエリアやジャンルに偏らないよう調整もしています）。それ以外の特集は、記事ごとに並べ方を決めていて、点数の順とは限りません。トップページの「みんなが見ている店」は、サイトで見られた回数の多い順です。「今日の話題店」は、新しさと、複数の媒体で紹介された数などから選んでいます。

番号や順位が小さいことは、その店が「いちばん良い」という意味ではありません。選ぶ手がかりの 1 つとして見て、自分の場面に合うかは各店の情報で確かめてください。

b) あえて外した店の理由を残す

名の知れた店を特集から外す場合、店名を伏せた類型（例:「個室の壁が薄いため接待向けには推さない」）として、外した理由を可能な範囲で記事内に書き残します。読者が自分のシーンに当てはめて判断できるようにするためです。

c) 数字の出どころを書く

順位・点数・「話題」などの数字を出すときは、何を数えたものかをその場に書きます。広告費の有無や運営の好みで、数字を動かすことはしません。数字は選ぶ手がかりの 1 つで、決め手にはならないと考えています。

08 — What We Never Do

運営のルールのうち、読者のみなさんにも関わる項目を公開します。 これらは「絶対にやらないこと」のリストです。

やらないこと

  • 独自性のない記事の量産はしない。他のメディアで読める内容ならば、わざわざ書きません。
  • 未確認の店舗情報は掲載しない。営業実態・基本情報は継続的にチェックします。
  • 特定店舗を不当に持ち上げる記述はしない。関係性・しがらみで評価を変えません。
  • 閉店店舗の情報を放置しない。確認でき次第、速やかに更新します。
  • SEO のための不自然な文章は書かない。検索最適化より読者の理解を優先します。
  • 他メディアのコンテンツを模倣・盗用しない。引用する場合は出典を明示します。

09 — Amendments

本規約は編集部で年1回以上見直します。 重要な変更があった場合は、冒頭の「最終更新」日を更新し、必要に応じて改訂履歴を残します。

規約について意見・指摘・質問があれば、お問い合わせからお知らせください。 読者のみなさんとの対話を通じて、この規約を育てていきたいと考えています。
